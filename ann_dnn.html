인공신경망(ANN)이란?

인공신경망(ANN, Artificial Neural Network)은 뉴런이 모여 서로 연결된
인간의 신경망 구조와 원리를 모방해, 여러 개의 퍼셉트론을 연결하여 만든 기계학습 알고리즘입니다.

인공 신경망

[그림 II-56] 인간과 인공지능의 비교 — 인간의 뉴런·신경망을 '모델링'하여 퍼셉트론·인공신경망을 만듭니다.

인공신경망은 역할에 따라 입력층, 은닉층, 출력층 세 가지 층(layer)으로 나뉩니다. 아래 그림은 각 층이 어떻게 연결되어 정보를 주고받는지 보여줍니다.

입력층 (Input layer)

외부로부터 입력 자료를 받아들여 시스템으로 이들을 전송한다.

은닉층 (Hidden layer)

입력값을 전달받아 가중치와 활성화 함수를 통해 입력 데이터에서 중요한 특징을 학습하고 추출하는 역할을 수행한다.

출력층 (Output layer)

입력값과 현재 시스템 상태에 기준하여 시스템 출력값을 산출한다.

[그림 II-57] 인공신경망의 구조와 각 층의 역할

인공신경망의 한계

모델이 깊어질수록 마주친 두 가지 큰 벽

초기의 인공신경망은 모델이 깊어질수록 최적의 가중치를 찾기 어려웠습니다. 학습 과정에서 기울기(오차를 줄이기 위한 방향)가 너무 작아지거나 너무 커지는 문제가 대표적입니다. 아래 시뮬레이터에서 층이 깊어질 때 기울기가 어떻게 변하는지 직접 확인해 보세요.

기울기 소실 vs 기울기 폭주 시뮬레이터

역전파는 출력층 → 입력층 방향으로 기울기를 전달합니다. 각 층을 지날 때 곱해지는 값(가중치 크기)에 따라 기울기가 사라지거나 폭발합니다.

층을 지날 때 곱해지는 값 (가중치 크기) 0.5
← 작음 (소실 위험)1.0 (안정)큼 (폭주 위험) →
역전파 방향 (오차가 거꾸로 전달됨)

학습 시간이 매우 오래 걸리는 문제

인공신경망 개발 초기에는 은닉층의 퍼셉트론이 많아질수록 계산해야 할 연결(가중치)의 수가 기하급수적으로 늘어나 학습 시간이 매우 오래 걸렸습니다. 당시 하드웨어 성능으로는 이를 감당하기 어려웠습니다.

▲ 은닉층(퍼셉트론)이 늘어날수록 연산량과 학습 시간이 급격히 증가

이러한 한계로 인해 인공지능 연구가 한동안 침체되는 '인공지능의 겨울'이 찾아왔습니다. 하지만 이후 GPU와 같은 병렬 처리 장치(하드웨어)의 발전으로 막대한 연산량을 감당할 수 있게 되면서, 인공신경망의 한계와 문제점을 개선한 심층 신경망(DNN)이 개발되었습니다.

심층신경망(DNN)이란?

심층신경망(DNN, Deep Neural Network)은 입력층과 출력층 사이에
은닉층을 2개 이상 지닌 인공신경망입니다. 은닉층이 '깊게(Deep)' 쌓여 있어 '딥러닝'이라 부릅니다.

아래 시뮬레이터로 입력 노드, 은닉층, 뉴런 수를 직접 바꿔 보며 신경망 구조가 어떻게 달라지는지 살펴보세요. 정보 전달(Forward Prop) 버튼을 누르면 데이터가 입력층에서 출력층까지 흐르는 모습을 볼 수 있습니다.

심층신경망은 어떻게 학습할까?

순전파 → 오차 계산 → 역전파의 반복

1

순전파

입력층 → 은닉층 → 출력층 방향으로 데이터가 흐르며 가중치와 활성화 함수를 거쳐 예측값을 계산합니다.

Forward Propagation

2

오차 계산

예측값과 실제 정답의 차이를 손실 함수(Loss Function)로 계산합니다. 이 오차(손실)가 작을수록 좋은 모델입니다.

Loss Function

3

역전파

출력층 → 입력층 방향으로 거꾸로 오차를 전파하며, 오차가 작아지는 방향으로 가중치를 수정합니다.

Backpropagation

순전파 역전파 — 이 과정을 수없이 반복하며 학습합니다

오차 역전파(Backpropagation) 기법

출력층에서 입력층의 방향으로 거꾸로 오차를 전파하면서, 가중치를 오차가 작아지는 방향으로 수정하는 방법입니다. 그렇다면 '오차가 작아지는 방향'은 어떻게 찾을까요? 바로 아래의 경사하강법입니다.

경사하강법 (Gradient Descent)

안대를 쓰고 산꼭대기에서 가장 낮은 골짜기(손실이 0에 가까운 곳)를 찾아 내려간다고 상상해 보세요. 발바닥으로 경사가 아래로 향하는 쪽(기울기)을 느끼며 한 걸음씩 내려갑니다. 역전파는 이 방법으로 가중치를 조금씩 수정합니다. 아래 시뮬레이터로 직접 체험해 보세요.

붓꽃(Iris) 다중 분류 모델로 보는 순전파 · 오차 계산 · 역전파

점검 포인트 — 순전파, 오차 계산, 역전파로 이어지는 딥러닝의 학습 과정을 정리할 수 있나요? 아래 붓꽃 분류 예제로 전체 흐름을 한 번에 따라가 봅시다.

딥러닝 붓꽃 다중 분류 모델의 학습

① 순전파

붓꽃의 4가지 특징(꽃받침·꽃잎의 길이와 너비)을 입력하면, 두 개의 은닉층(W₁·W₂와 활성화 함수 f₁·f₂)을 거쳐 세 품종일 확률을 출력합니다. 여기서는 버지니카 0.84로 예측했습니다.

② 오차 계산

실제 정답(버지니카)을 원-핫 인코딩 [0, 0, 1]로 표현하고, 예측 확률과 비교합니다. 손실 함수(교차 엔트로피)로 −log(0.84) ≈ 0.17의 오차를 얻습니다.

③ 역전파

계산한 오차를 출력층 → 입력층 방향으로 거꾸로 전달하며, 경사하강법으로 가중치(W₁·W₂)를 오차가 작아지는 방향으로 조금씩 수정합니다.

이 순전파 → 오차 계산 → 역전파 한 바퀴를 수없이 반복할수록 오차(0.17)는 점점 작아지고, 모델은 붓꽃을 더 정확하게 분류하게 됩니다.

딥러닝 붓꽃 다중 분류 모델의 학습 과정(순전파·오차 계산·역전파)
