합성곱 신경망(CNN)

Convolution Neural Network · 이미지 인식의 핵심

합성곱 신경망(CNN)은 데이터에서 지식을 추출하는 기존 방식과 달리,
데이터의 특징을 추출하여 특징들의 패턴을 파악하는 구조로 학습이 이루어집니다.

CNN 알고리즘은 합성곱 과정과 풀링 과정을 복합적으로 구성해 만들며, 정보 추출·문장 분류·얼굴 인식 등에서 널리 쓰입니다. 아래는 배 사진을 입력해 무엇인지 분류하는 전체 과정입니다.

① 합성곱 계층 (Convolution layer)

커널(작은 필터)을 이용해 데이터의 특징을 추출하는 과정으로 새롭게 만들어진 계층을 합성곱 계층이라고 합니다. 여러 개의 커널을 쓰면 합성곱 층도 여러 개 생기며, 이 과정은 파라미터 수를 효과적으로 줄여 주는 압축 과정이기도 합니다. 아래는 4×4 데이터를 3×3 커널로 합성곱하여 2×2로 압축하는 예시입니다.

[그림 II-60] 합성곱 과정 예시 — 원본값에 커널 가중치를 곱해 모두 더한 값을 모읍니다.

② 풀링 층 (Pooling layer)

풀링은 합성곱 과정을 거친 레이어의 크기를 줄여 주는 과정입니다. 정해진 구역 안에서 최댓값을 뽑는 최대 풀링과 평균값을 뽑는 평균 풀링이 있습니다. 불필요한 세부 정보를 줄이면서 중요한 특징은 유지해 계산 효율을 높입니다.

③ 완전 연결층 (Fully connected layer)

합성곱층과 풀링층을 여러 번 통과하여 추출한 이미지의 특징만 일렬로 만든 후, 일반적인 신경망인 완전 연결층으로 전달합니다. 이를 통해 이미지의 전역적인 패턴과 특징을 학습할 수 있게 되어, 어떤 정보를 가진 이미지인지 분류합니다.

순환 신경망(RNN)

Recurrent Neural Network · 순서를 기억하는 신경망

순환 신경망(RNN)은 순환 구조를 이용해 과거의 학습 결과를 현재 학습에 반영하여,
기존의 지속적·반복적·순차적인 데이터 학습의 한계를 해결한 알고리즘입니다.

RNN은 내부에 순환 구조가 있어 현재 입력을 처리할 때 이전에 처리한 입력들을 기억하면서 반영합니다. 아래 그림처럼 하나의 순환 셀(h)을 시간 순서대로 펼치면(unfold) 각 단계가 이전 단계의 정보를 이어받는 것을 볼 수 있습니다. 주로 음성 웨이브폼을 파악하거나 텍스트의 앞뒤 성분을 파악할 때 사용됩니다.

순환 신경망의 구조

x (입력)

각 시점에 들어오는 단어·신호

h (은닉 상태)

이전 정보를 기억해 다음으로 전달(가중치 v)

o (출력)

각 시점의 예측 결과

일반적인 딥러닝 vs 순환 신경망

문장 "너는 노래를 못 부르지 않아"는 이중 부정이라 사실 긍정(칭찬)입니다. 단어를 따로따로 보는 일반 딥러닝은 '못', '않아' 때문에 부정으로 잘못 판단하지만, 은닉층을 연결해 앞 단어를 기억하는 RNN은 흐름을 이해해 긍정으로 올바르게 판단합니다.

일반적인 딥러닝

단어를 독립적으로 처리해 앞뒤 맥락을 잇지 못합니다. 그래서 이중 부정을 놓치고 '부정'으로 판단합니다.

순환 신경망

은닉층을 연결해 이전의 입력값을 기억하므로 문장 흐름을 이해해 '긍정'으로 판단합니다.
